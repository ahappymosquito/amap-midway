# amap-midway

高德多点选址工具。打开页面会尝试定位并填入你的大致位置；一个地点即可搜索附近的美食、酒店、玩乐、咖啡、酒吧或景点。地点可逐个填写，也可分行或用分号批量导入。比较方式可选地铁通勤时间或直线距离。搜完会附带附近搭配推荐。点选后左上角浮窗列出多种路线，地图同一时间只显示一种出行方案。

当前版本：`0.2.2`

仓库：<https://github.com/ahappymosquito/amap-midway>

## 功能

- FastAPI 后端托管 API 和静态单页。
- 网页定位使用高德 `AMap.Geolocation`（自动转 GCJ-02，失败时用 IP 粗定位），地点 A 默认填当前位置；可随时点「使用当前位置」。
- 支持 1 到 6 个通勤点：单点搜附近，多点搜中间区域。输入地名会弹出高德候选，点选后带坐标。可用「导入地点」或在输入框粘贴，按换行/分号拆开。
- 比较方式可选「通勤时间」（最慢一侧地铁，可设上限）或「绝对距离」（直线距离，并选 1.5/3/5/8km 范围）。列表同时展示地铁、骑行和最远直线距离。
- 预算文案随选项切换：餐馆显示人均预算，酒店显示人均差标和人数合计。
- 选址品类对齐扫街榜2026：美食、酒店、玩乐、咖啡、酒吧、景点。美食可筛状元榜/烟火小店/极致甄选；其他品类可筛状元榜。搜完后「附近还可以」给出吃喝或玩乐搭配（轻量行程，不是完整旅游规划）。
- 酒店可用「温泉」「电竞」「独家」「华住会」「亲子」「民宿」属性（店名/标签关键词）和「大床房」「双床房」「家庭房」「套房」一级床型（携程该店房型列表）做可视化筛选。实时空房和房价不在站内展示，点进携程/美团核验。「在高德打开必住榜」跳转 `www.amap.com/ranking/{城市}/hotel`。
- 优先按真实地铁时长排序，而不是直线距离。
- 搜索时为前 3 名推荐预规划多种地铁方案和骑行方案。
- 搜索后只标注地铁站图标和站名；选中方案后标出途经站。
- 点选后地图只画地铁或骑行其中一种；路线带描边和低频闪烁。左侧方案合计前是地铁/出站骑行或走路/换乘，合计后是分段。下地铁后默认骑行，特别近才走路。
- 美团酒店跳转 H5 列表（城市 + 店名），餐馆跳转到餐搜索；携程用 `cityId` 和 `searchWord`，不再用会落到上海的 keyword-only 链接。
- 城市由第一个地点名自动推断，无需再填城市。
- 地点输入会保存在本机浏览器：下次打开自动填上次内容，并可点「最近用过」快速填入。
- 列表先展示最推荐的 3 家，其余折叠。
- 桌面端打开网页版美团/携程/高德；移动端高德可唤起 App。手机端筛选条放进下方面板，地图只留路线浮窗和状态条，避免互相遮挡。

## 环境变量

```powershell
$env:AMAP_WEB_KEY="你的高德 Web 服务和 JS API Key"
```

也可以在项目根目录创建 `.env`：

```text
AMAP_WEB_KEY=你的高德 Web 服务和 JS API Key
```

如果页面地图加载失败并出现 `USERKEY_PLAT_NOMATCH`，需要在高德控制台把 `amap.tingle272.xyz` 和本地 `127.0.0.1` 加入 JS API 域名白名单。

## 安装与启动

```powershell
poetry install
poetry run uvicorn app.main:app --reload
```

- 本地：<http://127.0.0.1:8000/>
- 线上：<https://amap.tingle272.xyz/>（旧域名 `amap.qrqto.club` 已弃用，会跳转到此）

服务跑在 `ts3` 的 `/home/ts3/amap_find`，由 systemd 服务 `amap-find` 监听 `127.0.0.1:8010`，Nginx 反代 `amap.tingle272.xyz`。

## API

- `GET /api/config`
- `GET /api/geocode?address=北控水务大厦&city=北京`
- `GET /api/geocode/suggest?q=望京&city=北京`：地名候选（高德输入提示）
- `POST /api/places/search`
  - `origins`：至少一个地点，可只给地址，也可带 `lng`/`lat`
  - `category`：`restaurant` / `hotel` / `play` / `coffee` / `bar` / `scenic`
  - `people_count`：人数
  - `budget_per_person`：单人差标
  - `sort_by`：`transit`（默认）或 `distance`
  - `radius_m`：可选 1500–8000，绝对距离模式下的搜索半径
  - `max_transit_min`：可选通勤上限（分钟）
- `GET /api/places/transit`：单段地铁时长
- `GET /api/places/route`：多种地铁方案和骑行折线，前端规划失败时回退使用

## 当前限制

- 酒店实时房价、空房和团购价不在本站内展示，需跳转美团/携程/高德。美团网页常要求登录或触发风控，真实浏览器里可继续；旧版 `www.meituan.com/s/` 已 404。
- 出站骑行时长由末段步行距离按约 3.5m/s 估算，不额外请求高德骑行接口。
- 地铁排序只对中心附近最优的一批候选调用高德公交接口，以控制配额。
- 地图上的地铁站是通勤点范围内的参考标注；途经站来自当前选中的出行方案。
- 扫街榜没有官方开放接口；本站用关键词召回做可视化筛选。网页已有美食/酒店/景点/烟火小店路径，咖啡/酒吧/玩乐独立榜尚未出现在 www.amap.com/ranking，站内跳转城市总览。
- 酒店属性没有官方筛选接口：华住会按汉庭/全季/桔子等店名识别。一级床型来自携程该店点评侧房型筛选列表；在售报价接口有反爬，站内不展示实时房价和空房。
- 酒店搜索会额外请求携程，前 24 家较慢；匹配失败则该店床型为空。
- 高德返回结果依赖 Key 权限、配额和 POI 数据质量。
- 地点历史只存在当前浏览器 localStorage（键名仍为 `amap_find.*`），清站点数据会丢掉；不上传服务器。
- 定位需要 HTTPS 或 localhost，并获得浏览器定位权限；拒绝权限时可手填地点。IP 粗定位可能只到城区。
